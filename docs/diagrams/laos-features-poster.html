③ SOP —— 三分钟跑起来

  1. 起服务：LAOS_LLM_*=… python bin/laosweb.py → 电脑开 http://localhost:8800
  2. 手机接入：Release 页下 laos-client.apk（首启填电脑 IP）或 Chrome 加主屏幕
  3. 对话：打字或 🎙 按住说话；🔊 开朗读；说的每句话自动进长期记忆
  4. 治理：审批卡四钮管权限；治理 tab 管 mode/grants/污点；审计 tab 看每一步
  5. 维护发版：unittest discover 全绿 → check_onboarding 门禁 → release.py --apply → tag 推送 CI 出 APK
