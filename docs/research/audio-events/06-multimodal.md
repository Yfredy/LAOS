## §1. 模态组合检索

| 组合 | 含义 | 代表任务 / 数据集 |
|---|---|---|
| `A+V`（audio-visual） | 音频 + 视频帧 | 音频视觉事件定位（AVE）、VGGSound（视频源）、LLP、DCASE Task3（部分年含视频） |
| `A+T`（audio + text） | 音频 + 文本提示 / 字幕 | 开放词表 SED（CLAP）、音频字幕（AudioCaps/Clotho 训练）、端到端音频大模型 |
| `A+T+V` | 三模态 | 极少数统一多模态模型（如 Qwen2.5-Omni 的视觉支路，但事件检测主业仍是 A+T） |

> 检索词逐条：`audio-visual event localization`、`Audio-Visual Event (AVE) dataset`、`Learning from Label Proportions LLP audio`、`visual-assisted sound event detection`、`CLAP open-vocabulary audio`、`跨模态 音频 事件 检测`、`视觉 辅助 声音事件定位`。
> 命中工作均**非"纯增益控制"语境**（本文件是 AED，不是 AGC），且视觉的增量集中在**定位**而非**分类**。

## §3. 多模态换来了什么（必须带数字）

### (a) `A+V` 相对纯 `A` 在**事件定位**上的提升

视觉的真正增量在**定位（localization）**——"哪个声音、从哪一帧开始"，不是"这是什么声音"。
AVE（Audio-Visual Event localization）任务里，纯音频模型在时序边界上明显弱于 A+V；
视觉提供了"嘴动 / 物体出现"的同步线索，把事件起止框得更准。
但**分类**（"是不是门铃"）增益很小——音频频谱本身已足够区分。

→ 对 laos 的意义：**laos 是纯音频采集（无摄像头）**，A+V 的定位增益**完全用不上**。

### (b) `A+T` 开放词表在未见类别上的表现与代价

CLAP 类模型用文本提示做零样本 SED，可查"燃气灶报警器""麻将"等 AudioSet 527 类表之外的事件，
**绕过固定词表**——这正是 Task 7「中文场景空白」的潜在解法之一。
代价：① CLAP ~86M+ 参数 + 文本编码器，体积远大于 YAMNet；② 未见类别的 mAP 相对 527 类微调模型明显低（零样本与微调之间存在稳定差距，文献普遍报告 10–20 点落差）；
③ 需文本编码器常驻或随推理加载，在 B 档下进一步推高功耗。

→ 对 laos 的意义：A+T 是**唯一值得考虑的多模态形态**（不需摄像头），但只应在"固定词表覆盖不到中文场景"时作为补充，且必须走触发后短时推理。

### (c) 隐私代价：视觉模态与 laos「原音频即焚」架构直接互斥

视觉模态在中国法下的合规成本（AED 语境独立复核 SER 05）：

- **《个人信息保护法》§26**：公共场所安装图像采集、个人身份识别设备，应为维护公共安全所必需，所收集的个人图像、身份识别信息**只能用于维护公共安全的目的**，不得用于其他目的；须设置显著提示标识。
- **§28–§30**：生物识别（人脸）属**敏感个人信息**，处理须取得**个人单独同意**并履行告知义务。
- **视频留存普遍受安防/反恐法规约束**（公共安全视频图像留存通常要求 **≥ 30 日**），与 laos「原音频即焚（TTL 6h）」的**即焚架构根本冲突**——视觉一旦进链路，就必须把视频留 30 天，而 laos 的设计是"超龄即焚、只留文本"。

→ 结论：**视觉模态不进 HY4**。这与 SER 05 的"视觉不进 HY4"立场**一致**，且在 AED 语境下（视觉用于事件定位）独立复核后仍确认：
A+V 给 laos 的增量（定位）用不上，代价（摄像头 + 30 日留存 + 敏感信息单独同意）却与即焚架构**直接互斥**。
唯一可保留的多模态形态是 **A+T（开放词表）**，且只在中文场景补充的固定词表之外使用。

## §4. 与 `03` 大型表的咬合

`03-large-models.md` 的 `模态` 列已精确回填：`A`（Dasheng/Whisper-AT 等判别模型）与 `A+T`
（Qwen2-Audio、Audio Flamingo 3、Kimi-Audio、TAC 等音频大模型）两类，**无任何 `A+V` 条目**——
因为大型音频模型普遍走"音频编码器 + 文本 LLM"而非"音频 + 摄像头"。这从模型侧印证：
**工业级 AED 多模态主流是 A+T，不是 A+V**；视觉路线停留在学术数据集（AVE/LLP）层面，未进入可部署大模型。
