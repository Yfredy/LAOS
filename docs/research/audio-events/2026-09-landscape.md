## §2. 中文场景空白（AED 特有，必须写）

AudioSet 本体来自**英文 YouTube**，中文家庭/社区环境事件分布与之显著不同：

- **未见或低召回的中文特定事件**：电动车报警器（高频、音色独特）、麻将洗牌声、广场舞音乐、燃气灶/一氧化碳报警器、中式门铃/鞭炮、方言呼叫。AudioSet 527 类虽有 `alarm` / `music` 但**粒度不足以区分这些中文场景**。
- **后果（具体失效）**：直接用英文预训练模型，上述事件要么落入 `alarm`/`music` 粗类无法细粒度触发，要么因频谱分布差异（中文环境混响、设备音色）导致**召回率低、误报率高**。
- **缓解手段（三条）**：① **自采小样本微调**：针对中文特定事件采百级样本微调 YAMNet/EfficientAT 分类头；② **只做粗粒度事件**：不追求 527 类细分，只保留"报警/人声/音乐/静默"等粗类，降低对英文细类的依赖；③ **开放词表绕过固定词表**：用 A+T（CLAP / Qwen2-Audio / TAC）以中文文本查询"燃气灶报警器"，避免固定英文词表覆盖不到。

> **严禁**：用 AudioSet AS-2M full 的 mAP 0.47 冒充"中文环境可用"。该数字只表征英文 YouTube 分布下的固定词表性能，不等于中文场景召回率。

## §3. 常驻检测升级决策（漏斗第一段：VAD 能量门 → 事件级检测）

直接回答：漏斗第一段从 VAD 能量门升级为事件级检测。

| 维度 | 分析 |
|---|---|
| 收益 | 减少无效唤醒（能量门把"空调噪声"也放行）；事件级触发更准（只在真实事件时记） |
| 代价 | ① **常驻功耗**：B 档下模型持续推理 = 400–1000 mW 税 + 推理，远超限 ≤25 mW 常驻预算（见 `05` §2）；② **误触发**：模型误报会触发更多蒸馏/留存，隐私含义放大；③ **隐私**：事件标签长期聚合可推断家庭结构与作息，属超范围画像 |
| 判定 | **不做"常驻事件级检测"**；**有条件做 = 事件驱动**：VAD 能量门仍为零成本第一道，AED 仅对能量门放行的"可疑片段"做二次确认（功耗回到"触发后短时"档） |
| 阈值 | 仅当：① 走出 proot 拿到 A 档（aDSP/Sensing Hub，mW 级）；② 且目标事件固定（可用小型 tagging 模型）；③ 且接受事件标签只改"是否蒸馏"不改"是否留存"（见 `07`）。否则维持能量门 |

## §4. 选型决策树

```
能否走出 proot 拿 A 档（aDSP/Sensing Hub）？
├─ 否（当前 B 档 proot）
│   └─ 常驻？ ── 否（推荐）→ VAD 能量门 + 事件驱动 AED（YAMNet TFLite Micro，触发后短时）
│       └─ 常驻？ ── 是 → 不可接受（功耗超标），维持能量门，不做常驻 AED
└─ 是（原生 App / A 档）
    └─ 事件类别固定？
        ├─ 是 → 小型 tagging/ASC（YAMNet / CP-Mobile），A 档常驻可行
        └─ 否（开放词表/中文特定）→ A+T（CLAP / Qwen2-Audio）走触发后短时或服务端批量
```

## §5. 与即焚架构的兼容性

- 事件标签**只改变"是否蒸馏"，不改变"是否留存原始音频"**——否则即焚被绕过（见 `07` 三条"不做什么"）。
- A+T 大模型若走服务端，原始音频需外传，**与即焚/本地优先冲突**，仅限非敏感场景或用户显式授权。
- 视觉模态（A+V）不进 HY4（见 `06` §3）：摄像头 + ≥30 日视频留存与即焚根本互斥。
