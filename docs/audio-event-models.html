结论

常驻检测升级：不做"常驻事件级检测"，有条件做"事件驱动"（VAD 放行后 AED 二次确认）。

  • B 档 proot 下常驻 AED = 400–1000 mW 税 + 模型推理，超 ≤25 mW 常驻预算 18–48 倍，不可接受。
  • 中文场景空白：AudioSet 来自英文 YouTube，电动车报警器/麻将/广场舞/燃气灶报警器等中文特定事件召回低；缓解 = 自采微调 / 粗粒度 / 开放词表（A+T）。
  • 视觉模态（A+V）不进 HY4：与即焚架构（TTL 6h）根本互斥，且触发 PIPL 敏感信息合规成本。

选型决策树：能否出端？否 → 维持能量门 + 事件驱动 AED（YAMNet TFLite Micro，触发后短时）；是（A 档）→ 固定类用小型 tagging/ASC，开放词表用 A+T 走短时/服务端。
