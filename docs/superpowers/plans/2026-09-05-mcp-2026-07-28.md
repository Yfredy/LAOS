# MCP 2026-07-28 升级（Tasks + Elicitation）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 laos 的驱动总线从 MCP 2025-06-18 子集升级到 [2026-07-28 规范](https://modelcontextprotocol.io/specification/2026-07-28) 的两个关键能力：**Tasks**（长耗时 syscall 异步化为可追踪任务，解除单工 stdio 上长命令阻塞驱动的痛点）与 **Elicitation**（server 执行中经 client 向用户要输入——把 `kernel.confirm` 从 CLI hack 升级为协议内机制）。

**Architecture:** 三块。① **请求双向化**：client 的 `_rpc` 读循环目前会把 server→client 请求当噪声丢弃（elicitation 会死锁）——重构为"请求拦截"循环（`on_server_request` 处理器，默认回 method-not-supported）；server 端 `serve_forever` 从 `for line in sys.stdin`（带 readahead 缓冲，与中途 readline 混用会丢数据）重构为逐行 `readline()`——这是 elicitation 的硬前置。② **Tasks**：server 端 `tools/call` 带 `task` 参数时入线程池异步执行（`tasks/get`/`tasks/result` 查询），initialize capabilities 声明 `tasks`；client 增 `call_tool_task`/`task_result` 轮询；kernel `syscall(..., task=True)` 走任务路径（`LAOS_TASK_TIMEOUT`）。③ **Elicitation**：server 增加 `elicit(message)`（写请求、等响应），decline 抛 `PermissionError("EDENIED: ...")` 走既有 errno 透传；kernel 把所有驱动的 `on_server_request` 路由到 `self.confirm`；`drv_proc` 增 `LAOS_EXEC_ELICIT=1` 模式示范。**范围红线**：elicitation 仅支持同步 tools/call 路径（server 主循环串行读 stdin，task 线程内 elicit 会与主循环抢 stdin——文档明确禁止）。

**Tech Stack:** Python 3.10+ 标准库（threading/json），零第三方依赖。

**Spec:** `docs/research/2026-09-05-agentos-next-steps.md` §一.1 / §二#4；[MCP 2026-07-28 规范](https://modelcontextprotocol.io/specification/2026-07-28)。

```python
    def serve_forever(self) -> None:
        """stdio 主循环：逐行读 JSON-RPC 请求（readline 而非迭代器，
        便于 elicit 在工具执行中途再读一行响应而不丢缓冲数据）。"""
        while True:
            line = sys.stdin.readline()
            if not line:  # EOF
                break
            line = line.strip()
            if not line:
                continue
            try:
                req = json.loads(line)
            except json.JSONDecodeError:
                self._write({"jsonrpc": "2.0", "id": None,
                             "error": {"code": _JSONRPC_PARSE_ERROR, "message": "parse error"}})
                continue
            resp = self._handle(req)
            if resp is not None:
                self._write(resp)
```

3b. `MCPServer.__init__` 增加 `self._req_id = 10000`；新增 elicit：

```python
    def elicit(self, message: str, schema: dict | None = None) -> dict:
        """server→client 请求用户输入（MCP elicitation/create，同步路径专用）。

        仅允许在 serve_forever 主线程的工具执行中调用——task 线程内调用
        会与主循环抢 stdin（规范上也不允许）。
        """
        self._req_id += 1
        req_id = self._req_id
        self._write({"jsonrpc": "2.0", "id": req_id, "method": "elicitation/create",
                     "params": {"message": message, "requestedSchema": schema or {}}})
        while True:
            line = sys.stdin.readline()
            if not line:
                raise RuntimeError(f"EIO: stdin closed during elicitation: {message!r}")
            line = line.strip()
            if not line:
                continue
            resp = json.loads(line)
            if resp.get("id") != req_id:
                continue  # 与本次请求无关的消息（理论上不应出现）丢弃
            if "error" in resp:
                raise PermissionError(f"EDENIED: elicitation rejected by client: "
                                      f"{resp['error'].get('message', '')}")
            result = resp.get("result") or {}
            if result.get("action") == "accept":
                return result
            raise PermissionError(f"EDENIED: elicitation declined: {message!r}")
```

```python
    def call_tool_task(self, name: str, arguments: dict) -> str:
        resp = self._rpc("tools/call", {"name": name, "arguments": arguments,
                                        "task": {}})
        task = resp.get("result", {}).get("task") or {}
        if not task.get("taskId"):
            raise RuntimeError(f"driver {self.name} did not accept task mode")
        return task["taskId"]

    def task_result(self, task_id: str, timeout_s: float = 30.0,
                    poll_s: float = 0.05) -> CallResult:
        import time as _time
        deadline = _time.monotonic() + timeout_s
        while _time.monotonic() < deadline:
            resp = self._rpc("tasks/result", {"taskId": task_id})
            if "error" in resp:
                return CallResult.fail(resp["error"].get("message", "unknown error"))
            result = resp.get("result", {})
            if result.get("status") == "completed":
                content = result.get("content", [])
                if result.get("isError"):
                    return CallResult(False, content,
                                      content[0].get("text") if content else "EIO")
                return CallResult(True, content)
            _time.sleep(poll_s)
        return CallResult.fail(f"ETIMEDOUT: task {task_id}")
```
