为什么做：审判席在循环外the thesis

行业自己的论证

Lilian Weng《Harness Engineering for Self-Improvement》（2026-07-04）列出 RSI 七大瓶颈，第五条原文立场：评估器与权限控制应放在进化循环之外。AIDE² 实证：reward hacking 从 55% 降到 32%——但仍有 32%，且该性质未被显式优化。

RSI 论文六周一浪（环境 RSIGym / 正则化 RRSI / 探索 Dream-RSI / 路线图 Last AI），首届 ICLR26 RSI Workshop 录用 110 篇——安全与评测类占比显著。

laos 的对应动作

基座是 Linux 内核，Agent 是新负载；RSI 让负载变成「会自改写的负载」。OS 史的回应不是跟着进化，而是 W^X / 不可变内核文本 / 代码签名——laos 就是这套动作在用户态的延伸：内核不自改写，负载可以，但每个自改写动作过闸、留痕、可回滚。
