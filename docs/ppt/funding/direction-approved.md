## 裁决（艺术总监角色，自主子代理模式）

**选 A · 融资台账（黑金 2.0）**

1. 母题同构（决定性）：laos 核心资产 = FleetLedger（先扣账后派发、不可抵赖）；融资 = 资本的记账与问责。台账行 / 金色合计 / 大写数字壹贰叁（中文账防涂改数字）= 形式即论证，只可能从这份内容长出来。
2. 资本场合温度：黑金 = 金库与审计所的权威克制；暗场投屏聚焦力优于白纸反光。B 可读性最佳但气质是尽调文档，15 页路演需要「场」。
3. 品牌连续性：wave-1 介绍 deck 已用黑金台账，同一项目两份物料同一视觉资产 = 投资人侧品牌记忆。
4. 受众错位排除 C：终端风是开发者暗号；大面积琥珀之「快」与审计之「克制」相抵。

落选方向吸收：B 红笔批注 → 「示例」红章与诚实呈现标注语法；C 分段清算条 → P14 用资分段条。

## 附：形式推导五问（主 deck 开工前已答）

- 叙事角色：pitch 弧线——hero 封面 → thesis 一页 → 痛点（反派）→ 时机（紧迫）→ 产品+三壁垒（权威）→ 竞争（卡位）→ 进展（凭证）→ 商业/市场/路线/融资（算账）→ 团队风险+收束（信任+金句）。
- 观众距离：3m 投屏 + 1m 笔记本细读双场景；数字大字化（96px 级），正文 ≥20px。
- 视觉温度：权威、冷静、可审计、资本感；金=资本与合计，朱砂=拒绝/示例标注（语义化用色）。
- 容量估算：每页一论点一图式，重页（P5/P6/P10）以单图式 + ≤3 支撑块控制，912px 内容净高内闭合。
- 视觉母题：台账（FleetLedger）。**form 来自内容哪里**：来自产品自己的不可逆计价账本——大写数字壹贰叁是中文账本的防涂改装置，与「事后不可抵赖」同义。
