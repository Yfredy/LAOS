SHEET 02 · PROBLEM STATEMENT

Agent 拿着 root 裸奔。

rm -rf ~

一句工具调用删光家目录；"请小心"写在提示词里——恳求不是强制。

恶意 MCP 工具

剪贴板、通知、短信直接外发；装一个工具等于开一扇门。

不可逆无计价

卸载、发送、删除与读取同权——没有记账，没有回放。

缺的不是更聪明的模型，是操作系统：能力 · 调度 · 审计 · 记账 · 隔离。

laos · Linux AgentOS
把风险说具体：删库、隐私外发、不可逆操作无门槛三张风险单。共同根因是 Agent 没有操作系统——所以解法不是更好的提示词，是能力边界。

SHEET 03 · DESIGN THESIS

Linux AgentOS = Linux kernel + Agent + MCP

namespace — 隔离视图（mount/pid/net）

cgroup v2 — 资源上限，失控不拖垮宿主

seccomp BPF — 系统调用白名单，真拦截

Landlock — 路径沙箱，未授权不可见

laosd = 薄内核

只做语义层：能力表、审计、记账、确认。设备全部交给 MCP 驱动；内核补丁数为零。

0 KERNEL PATCHES

laos · Linux AgentOS
核心公式一句话讲完。四个强制原语都是 Linux 现成的，我们一个都不改，只是组合；laosd 只做薄薄的语义层。零内核补丁意味着随时能跟上上游。

SHEET 06 · ENFORCEMENT SPEC

强制发生在内核，不在上下文窗口。

seccomp BPF

进程级系统调用白名单——拦截是真实的，不依赖模型自觉。

cgroup v2

驱动子进程 CPU/内存上限；驱动失控只死驱动。

eBPF + CoW

行为画像与执行隔离，给每个 Agent 建档案。

复用 Linux 强制原语 × 3 —— 不发明新机制，只做正确组合。

laos · Linux AgentOS
强调"真拦截"：这三件都是内核级机制，模型再聪明也绕不过。我们不发明新的安全机制，只是把 Linux 三十年积累的原语组合到 Agent 场景。
