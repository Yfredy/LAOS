论文是什么AuraSE, arXiv 2610.06632v1

问题：生成式增强会幻觉

“说得更好听但改了内容”——换词/插音/丢弱语音/漂说话人。实测（带混响 WER）：LLaSE-G1 28.78%、SGMSE 22.15% vs 噪声输入 10.82%——生成式增强一度比不增强更毁内容。

杠杆一：双流 MMDiT

转写与退化音频联合注意力但各留专属通道——文本补内容、声学保说话人。GT 文本 WER 7.69% vs 单流 10.97%。

杠杆二：IPO

8 组推理配置出候选 → 多目标奖励（4:2:2:2，保真 60%）排序成偏好对 → 锚点随模型前移的成对更新 → 蒸馏回固定 10 步 ODE。12 项指标 11 项第一。

最有普适价值的一条：GT-DPO 崩点——拿真值当偏好赢家 WER 恶化到 13.35%；只有“模型自产相对偏好 + 移动锚”有效。与 laos“实测不引宣称”、JitMem“相对优于绝对”三方独立收敛。

奖励面怎么用three steps

驱动/编排侧组装

spec = RewardSpec(
  weights={"OVRL":4.0,"WER":2.0,"SIM":2.0,"SBS":2.0},
  lower_better=frozenset({"WER"}), # 自动翻转
  version="aurase-4222") # 变更即升版
rewards = aggregate(candidates, spec)
# → 填 EvolveResult(reward_version=spec.version, ...)

审计自动透传

执行器返回带 reward_version → evolve.run 审计行自动多出该键（仅非空）；权重变更=新版本号，历史不可变可追溯——锚点治理。

手算锚点速查

三候选 4:2:2:2 → [0.3, 0.8, 0.6]；总分王不是 OVRL 最高者；全指标垫底=0.0 闭端；θ=锚时 IPO 损失=log 2。

补：laos 的差异化价值what laos adds back

奖励模型在循环内、无外裁判席

IPO 的权重人工固定、奖励模型被当真值——作者自认“mitigating 非 eliminating” hacking。laos 立论（评估器与权限在进化循环之外）补位：权重/奖励模型变更走版本化审计——本波 reward_version 就是这颗种子。

“逐话语穷举部署不起”是调度问题

best-of-8 全知全能但太贵，IPO 用蒸馏换部署延迟——“用训练时算力换部署时延迟”的经典调度权衡，与 evolve iterations 上限、mixed execution 结论同域。

ASR 条件是外部幻觉入口

转写由 Whisper 一次性固定，作者承认依赖仍在。laos 三通道 ASR + AgenticSR refiner 正是条件输入治理层；论文 WER 对参照转写而非条件转写评分=“抄条件不得分”，与 laos 引用/实测不混写同构。

明确不做 + 红线维持what we refused

三条不做（防走偏）

  • jitmem curator 不引入差距比例采样——确定性 top-k 是可调试/可复现特性，briefing 随机化有害无益
  • SE/生成式音频本体不做——零依赖红线；未来只可能 drivers 子进程形态
  • telemetry 冻结面不动——23 事件/138 字段过设计评审；三维约定立在 drivers/README

红线维持（不改判）

  • auto-gain/04“生成式不进记忆链路”维持——最优系统 WER 仍 8.22%，幻觉可压不可灭
  • 生成式产出只进评测副本不进记忆副本（与 AGC“增益只作用于送推理副本”同一条红线）
  • 保真 ≥60% 是文档级约定（违规 review 层拦，不做代码强制）

  • LLM 后端 BLOCKED：唯一 key 是内网网关会话密钥（七端点 401）
