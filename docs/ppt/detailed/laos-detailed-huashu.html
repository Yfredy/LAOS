复用四件内核遗产 —— 三十年强制原语，不是新发明

NS

namespace · 隔离

每个 Agent 自己的视图——mount / pid / net 互不可见。

CG

cgroup · 配额

资源上限：失控的驱动只死自己，不拖垮宿主。

SC

seccomp-BPF · 系统调用过滤

白名单真拦截，不依赖模型自觉。

LL

landlock · 文件沙箱

未授权路径直接不可见。

内核遗产映射到 LAOS语义
MCP Server= 设备驱动设备接入的唯一形态
tool call= 系统调用每次过闸，可拒绝
laosd= 薄内核只做语义层，不做重活
能力表 caps= 权限位没给的能力，不存在

关键判断：Agent 时代的「内核」不是重写调度器，
而是给工具调用装上 syscall 语义。
