### Added
- feat(laosweb): **agent 记忆闭环**（v0.31.0 对话面的自然续步：agent 不止写记忆，更用记忆）。① **用户话轮落库为"人写行"**：`remember(kind="chat", origin="user")`——用户在对话里说的话就是人写行，自动获得 jitmem 去重豁免与"人写一行胜模型行"保护；只记用户侧（助手回复可由模型再生，入库只会污染召回面）；`LAOS_CHAT_MEMORY=0` 可关（默认开——个人 agent 的记忆即产品）。② **相关记忆注入 system**：每轮按问句 `recall(k=4)` 拼成 system 附注（"相关记忆（此前留存，供参考）"），agent 答问时带上下文；内容进 prompt 但**不进审计**（event:'llm' 仍只记元数据）。③ reset 只清会话不清记忆（跨会话/跨重启的 agent 记忆——MemoryStore 本就 JSONL 持久）；记忆失败静默不阻断对话链路。4 例新增测试（人写行落库/环境开关/召回注入命中/reset 保记忆），全套 **1037 全绿**（1033→1037，OK skipped=5）；交接门禁二度实战：红 1 条（1033→1037）→同步→绿
