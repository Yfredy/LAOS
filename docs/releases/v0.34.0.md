### Added
- feat(clients): **预编译 APK 交付**（用户反馈"release 只有代码没有编译物"的补齐——laos 本体纯 Python 源码即成品且 GitHub 自动带 source zip，唯一需要编译的交付物是安卓壳）。① `.github/workflows/apk.yml`：打 `v*` tag 自动 `assembleDebug`（JDK17 + Android SDK + Gradle 8.9——仓内刻意不提交 wrapper 二进制），改名 `laos-client.apk` 挂到对应 Release 页（约 5–10 分钟出包；debug 签名可直接侧载）。② **运行时地址配置**：MainActivity 首启弹框输入 laosweb 地址存 SharedPreferences——预编译 APK 的 URL 不再焊死在构建里（改地址=清除存储）。③ network_security_config 预编译包放行明文全域（无法预知用户电脑 IP，单 IP 白名单会挡连接；取舍写进注释，在意者走路 B 源码自建收紧）。④ README 三路线重排：**C 直接下 APK（最省事）/ A PWA（零代码）/ B 源码自建**。壳 0.2.1/versionCode 2；laos 主库零改动，**1051 绿不变**（交接门禁本波无漂移）
