## 生活日志双记忆 — 全天候录音升级为生活记录

时域节律 + 频域声景双记忆，每日日记自动生成第六章；全程零新增常驻内存（手机内存预算红线，权威时域存储在 ADSP）。

### Added
- **`laos/soundscape.py` 频域声景特征**：Goertzel 七分带（125Hz–6kHz）+ 复用 loudness 的 LUFS/True Peak/PLR（纯 stdlib，-inf 全 floor 防护）——journal 原音频即焚**之前**对每段提取，按 (日期, 小时) 聚合为 `kind="soundscape"` 文本记忆（≈2KB/天）
- **`laos/rhythm.py` 时域节律档案**：journal 记忆按**拾音时刻**（正文 `[HH:MM]` 前缀优先）聚合成小时画像——夜间批量跑不会把全天坍缩进一个小时
- **`bin/journal.py`**：`--diary` 一键收尾生成当日日记（cron/Tasker 每晚一条命令）；`spectral=False` 可关声景
- **`bin/diary.py` 第六章「今天的节律与声景」**：节律行（最活跃时段/主导情绪）+ 声景行（LUFS/峰值带/flatness），并固化当日 `kind="rhythm"` 快照——`mem.recall("2026-10-09 14时")` 时间检索成为可查询问题
- **功能版图**（docs/superpowers/plans/2026-10-09-aor-lifelog.md §功能版图）：语音情感识别已在线、环境场景识别本波奠基（特征层）、AGC 模型版维持不加、听觉健康/作息画像数据本波开始积累

### Fixed
- `rhythm` 小时桶改取拾音时刻前缀（夜间批量不坍缩）；`describe` 失败不炸批（先算后记）
- 预存 bug：`journal.py` 默认转写曾引用不存在的 `drv_ear.transcribe`（裸跑 AttributeError，测试 monkeypatch 掩盖）——指向真实导出名 `ear_transcribe` + 回归钉

**1140 项测试全绿**（主库）· 零新依赖 · 记忆增量 ≈3.5KB/天（纯文本）
