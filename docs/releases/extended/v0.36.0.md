## 录音回放 rec.replay — 全天候录音新能力

"帮我这个时间点前 15–20 秒回放"——没听清/听障场景的一键重听 + ASR 文字。

### Added
- **`laos/ringbuf.py` 内存环形缓冲**：纯 stdlib 线程安全；内存预算红线——默认 30s=960KB、clamp 5..120s（`LAOS_REPLAY_RING_S`）；权威时域存储在 ADSP，AP 环冲只是回放镜像
- **`mic.replay` 驱动工具**：监听会话环冲快照落 var/ear/replay/（mtime 序只留 20 份即焚）；`LAOS_REC=0` 同闸门 EACCES
- **内核内建 `rec.replay`**（阻塞型 to_thread）：跨驱动同步组装 mic.replay→ear.transcribe 三通道转写；`event:"mic"` 审计成败双路只记元数据 + syscall 审计 result 按 tool 抹除（转写文本与音频永不入任何审计记录）+ sentinel private_tools 置污
- **laosweb `/api/replay` + 「录音回放」卡**：15/20/30/60 秒选择、音频 base64 重听、ASR 文字
- **evolve 奖励治理面**（并行波随合并）：RewardSpec+aggregate（AuraSE 4:2:2:2 防单指标 hacking）+ reward_version 版本化 + Repro 区 AuraSE-IPO 复现（+23 区测）
- 摘要模型扩展位预留（本期未实现）

### Fixed
- 终审修复波：syscall 审计转写抹除（C1）、失败路径 event:mic 补账（M2）、replay 目录 mtime 序（M1）、README 模块数 47→49（I1）
