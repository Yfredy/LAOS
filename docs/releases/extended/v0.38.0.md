## 回放摘要 —— 录音回放的 AI 摘要扩展位兑现

v0.36.0 预留的摘要模型扩展位落地：回放不止能重听和转写，还能一键压成一句中文摘要（听障/没听清场景的第三层辅助）。

### Added
- **内核 `rec.replay` 新参数 `summarize`（默认 false，全 opt-in）**：转写文本经 `laos/llm.py` LLMClient（`LAOS_LLM_*` 三值装配）压成 ≤60 字中文摘要——"只依据给定文本，不要补充"
- **软降级状态机 `summary_status`**：`off`（未开）/ `ok` / `unconfigured`（LAOS_LLM 未配置）/ `failed`（LLM 出错）——回放本体（音频+转写）永不因摘要失败
- **隐私口径不变**：摘要是转写的衍生文本，同样不入任何审计记录；`event:"mic"` 元数据审计增加 `summarize` 布尔位
- **laosweb「录音回放」卡新「摘要」开关**：勾选后响应渲染摘要行（accent 色）；未配置时显示一句配置提示
- **发版内容归档制度化（本波起）**：`docs/releases/` 每版一文件（元信息头+详细正文+索引），`scripts/gen_release_notes.py` 发版后生成对齐——41 个历史版本已全量补档
