## 2. 任务 2：飞书文档的交付边界

本机**没有连接飞书 MCP/连接器**（检索 `feishu` 返回 0 个工具），因此无法直接在你的飞书空间创建文档。

本包交付的是**可直接落地的成稿**：

1. 打开飞书 → 云文档 → 新建文档；
2. 将 [01-feishu-doc.md](01-feishu-doc.md) 全文粘贴（或使用「导入文档」选择 Markdown）；
3. 表格会转成飞书表格；建议把 `#`/`##` 标题保留为飞书大纲层级，便于生成目录；
4. 若要在团队空间发布，按飞书权限设置授予「组织内可阅读」。

文档本身已按飞书阅读习惯控制段落长度，不依赖 HTML/脚本，粘过去即可用。
