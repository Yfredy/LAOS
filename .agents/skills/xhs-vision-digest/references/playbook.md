# 读图实战手册（playbook）

来自 2026-10-09 一次 134 篇 / 1706 图全量调研的实测经验。所有结论都是踩过坑的。

## 1. 批量策略实测

| 批量 | 表现 |
|---|---|
| 双张批 | **最稳**，回传几乎不丢 |
| 3 张批 | 稳，偶尔丢尾部 |
| 4-5 张批 | 可用但丢失率明显升高；长回传（>1500 字/图）时尾部幻觉率上升 |
| 单张 | 兜底与仲裁用 |

主对话直读时用双张批；只有赶进度才上 4 张批，且必须做页码校验。

## 2. 页码连续性校验（最强仲裁信号）

多数技术笔记每页图有编号标题（`## 2. 标题`、`## 3. …`）。读图前先扫一遍各图回传的编号：

- 编号应随图序单调递增；**断档/跳跃 = 该图回传可疑** → 单张重读。
- 同一篇笔记两次读出不同编号序列 → 后读若与图序吻合则取后读。
- 无编号的笔记（散文式/纯图）退化为幻觉签名检查。

裁决版 prompt（单张重读时用，比标准版更收紧）：

> 这张图是《XX》笔记的第 N 页。请只转写图内真实存在的内容：正文段落、公式、表格每一格、代码块、图示框和标签。若图内没有表格/某元素请如实说明"无"。中文输出，不要补充图内不存在的内容。

## 3. 幻觉签名全清单

1. **尾部乱码洪水**：回传末尾出现成片 `\n`、重复占位符、无意义符号——前半通常有效，剔除污染段。
2. **虚构 meta 段**：出现"与 XX 的关系（up 原文无，转写者补充）"式自注——图内不可能有，整段剔除。
3. **无关内容注入**：技术笔记里突然出现市场规模、培训广告等无关段落——剔除并警惕该图整体。
4. **同图异读**：同一 URL 两次回传实质不同（如一次"FRCRN 原理"一次"MP-SENet 原理"）——单张重读裁决。
5. **空回传 / "请您重新提问"**：直接重试，通常恢复。
6. **429 速率限制**：重试即可；连续失败降低批量。

处置原则：**污染段剔除后，剩余有效内容照常使用；整图无法仲裁的，在 digest 中注明"该图存疑"并降低该篇结论权重。**

## 4. transcript 文件格式（Agent 读图阶段的落盘产物）

```
# 转写原始记录：《标题》
- note_id / 分组 / 图数 / 读图方式（Agent并行|主对话直读）/ 日期
- imgs URL 列表（注明已过期仅存档；本地备份路径）
---
## 图 1/N
（完整转写文字，含页码编号标题）
## 图 2/N
…
```

- 每图一节，图序即文件节序；待仲裁图在节首标 `<!-- 待仲裁:图N -->`。
- 范本：本 skill 目录 `assets/transcript-sample.md`。

## 5. Agent 并行读图的注意点

- 每个子代理领 **1 篇笔记全部图**（不是几张跨篇的图）——页码连续性校验需要整篇上下文。
- 子代理 prompt 里给出该篇全部 URL 列表 + 标准转写 prompt 原文 + 幻觉处置规则（本文 §2/§3 的精简版）。
- 子代理回传只要一句话总结（成功/存疑/路径），全文写文件——控制主对话上下文。
- 大批次（>30 篇）分波派（run_in_background 或每波 5-8 个），防速率限制。
- 子代理声称"无法调用视觉工具"时（环境差异），该篇由主对话双张批读兜底。

## 6. 对账（收尾必做）

- 文档分组标题声明的 篇数×图数 Σ 必须 = manifest 实数（例：134 篇/1706 图）。
- digest 条目数可能 < 篇数（合并条目要在文中说明，如"K26/K27 四篇并两条"）。
- INDEX 登记前 Read INDEX，插在同系列前作之后；头部计数 +1 并注明日期。

## 7. 已知坑

- CDN URL 数小时过期：采集完立即下载本地 webp；过期 URL 仅在 transcript 头部留档追溯。
- Edit 工具长串匹配在千行文档上必失配：追加一律 python heredoc。
- 视觉模型对表格数字的转写偶有位级错误（3.83→3.8）：关键数字在 digest 里注明"以原文图为准"或交叉引用多篇互证。
